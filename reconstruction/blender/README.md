# 600 Stockton Street — Blender Reconstruction

## Purpose

This folder contains the 3D reconstruction of 600 Stockton Street.

The Blender model will be developed chronologically rather than as a
single static building.

---

# Model Structure

The Blender scene should eventually contain collections for:

- Site
- 1886–1887
- 1909
- 1913–1915
- 1919
- 1921
- 1930s
- 1953
- Present
- Evidence
- Environment
- Cameras
- Lighting

---

# Modeling Principle

The first model should represent massing rather than architectural detail.

The sequence is:

```text
Footprint
   ↓
Floor height
   ↓
Building mass
   ↓
Wings
   ↓
Courtyard
   ↓
Roof
   ↓
Facade
   ↓
Architectural detail
